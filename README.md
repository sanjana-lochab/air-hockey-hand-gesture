# Air Hockey — Hand-Controlled Two-Player Game

A real-time two-player Air Hockey game that uses a webcam and computer vision to control paddles through hand movements. The system processes webcam frames using HSV color segmentation, contour detection, and centroid tracking to determine hand positions and map them to paddle movement.

The game includes real-time ball movement, paddle and wall collision detection, dynamic ball-speed increase after paddle collisions, randomized ball direction on reset, and score tracking with a first-to-5 winning condition.
